# 星海工坊 2.0.0-dev.26

dev.26 是减负与边界修复版：

- “人物”只用于魔法少女、魔人、关键凡人等长期重要人物；直接安装才写现有 `/重要人物/<姓名>`。
- “生灵 / 配角”用于星灵、魔物、使魔、灵兽、路人等轻量设定，只写入聊天叙事，不进入 `/重要人物` 和 NPC 控制台。
- 人物发布页只暴露当前 Zod 已存在且常用的字段；性格、背景、战斗方式等作为叙事硬设定保存，不创建新 MVU 路径，也不自动塞进钩子/秘密。
- 玩法、装束、能力、物品等发布页整体减负；卡片自动简介压缩到约 108 字并最多显示 3 行。
- manifest 增加 GitHub `homePage` 与 `auto_update: true`。要让 SillyTavern 出现分支/提交与更新按钮，扩展目录本身必须由 Git 仓库安装；手工复制形成的 `(-)` 安装需要最后重装一次。
- dev.24 的作者编辑、真实点赞/下载、SillyTavern 世界书导入、导入作品上传选栏、stage3.7a-r1 管理后端继续保留。

冻结：OAuth/Auth、CloudBase Session、compat、发布后端、stage3.7a-r1、数据库 7 种 content_type、世界书执行器、Zod、星辉内核、事件推进器。
