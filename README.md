# 星海工坊 2.0.0-dev.29

dev.29 聚焦“人物长期记忆 + 核心伙伴”，并保持 dev.28 已通过的更新入口、云端读写与 UI 结构：

- `角色 / 人物` 作品新增合法长期人设映射：性格、言行模式、背景要点、补充设定。外貌继续使用一个自由文本字段，不为身高、三围、发色等另造变量。
- 酒馆世界书 / 外部人物文本导入时，客户端只按明确字段名做确定性提取；不调用 AI 猜分类。无法识别的原文仍完整保留，并把精简备份放入补充设定。
- `生灵 / 配角` 仍与长期人物分开。星灵是例外：星灵作品可直接安装到主角已有 `/主角/星灵` 伙伴槽，不会进入 `/重要人物`。魔物、使魔、灵兽、路人仍只作轻量剧情设定。
- 配合本批世界书 / Zod / 星辉内核，魔人使用 `/主角/本源/{名号,特征,状态}` 作为自身本源核心，不把本源当第二个人物。
- dev.28 的外层扩展更新卡、横排按钮、能力表单、短简介、作者编辑、真实点赞下载均保留。
- OAuth/Auth/compat、CloudBase 后端、数据库 content_type 与 stage3.7a-r1 保持冻结。
