# 星海工坊 2.0.0-dev.30

dev.30 把“人物作品”从大段补充文本升级为可单独寻址的结构化人物卡，并与开场人物名册、NPC 控制台和 MVU 使用同一套字段。

- `人设.长期事实.<短标题>`：保存不好硬分成性格/背景/爱好的稳定人物事实；一条事实一个变量。
- `特性.<名称>.{系别,类型,效果}`：保存被动天赋、体质、常驻效果；不再伪装成 0 蓝耗招式。
- `招式.<名称>.{档位,系别,类型,蓝耗,效果}`：人物上传页可直接录入正式技能，并按现有档位/蓝耗范围校验。
- `背包.<名称>.{数量,类别,描述}` 与 `星器.<名称>.{类型,品阶,契合,效果}`：普通装备和真正星器分开记录。
- `关系.钩子` / `关系.秘密` 保持独立字段，不再混进补充设定。
- 原始作者文本保存为作品 `source.rawText` 档案，不直接写入 MVU；`人设.补充设定` 仅保留旧档兼容用途。
- 新建条目名称会阻止路径保留字符，避免点号/斜杠等破坏变量路径。
- 人物安装仍直接写完整 `/重要人物/<姓名>` 对象；开场名册会保留长期事实、特性、招式、物品、星器，不再压扁丢字段。

配套 dev.30 世界书 / Zod / 星辉内核还为**主角**增加同构 `/主角/特性`，魔法少女/守护者和魔人都可使用。

## 本次保持冻结

Discord OAuth、CloudBase Session、公共读取、云端发布、ownership / manage、数据库 `content_type`、compat 等已实机闭环模块不重构。当前 publish/read/manage 后端对 `person.payload.source` 只做数组级校验，不裁剪嵌套人物字段，因此 dev.30 无需改云端协议或数据库。
