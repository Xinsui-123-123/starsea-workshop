# 星海工坊 V2 当前架构（dev.29）

## 人物 / 生灵边界

- `type=角色` / cloud `content_type=person, subtype=character`：长期重要人物，安装到 `/重要人物/<姓名>`。
- `type=NPC` / cloud `content_type=person, subtype=support`：轻量“生灵 / 配角”。魔物、使魔、灵兽、路人不写 `/重要人物`。
- 星灵是 support 中的特殊类型：安装时写主角自己的 `/主角/星灵`；不会成为 NPC。
- 历史 `subtype=npc` 继续按长期人物兼容；`subtype=support` 才归生灵 / 配角。

## 长期人物记忆

与 dev.29 配套世界书 / Zod 使用：

- `人设.性格`：长期人格倾向。
- `人设.言行模式`：说话、做事和压力下反应。
- `人设.背景要点`：持续影响选择的经历 / 动机。
- `人设.补充设定`：其他长期硬设定。

`档案.外貌` 仍是整体自由文本，可写身高、体型、三围、发色、瞳色等；只有确实需要逐部位长期白描时才使用 `躯体`。

外部人物世界书导入不调用 AI。只识别明确标签（姓名、性格、言行模式/说话方式、背景/经历、外貌/身高/体型/三围/发色/瞳色等）；无法识别内容保留在原文，并把精简备份放入补充设定。

## 核心伙伴 / 本源

- 守护者：`/主角/星灵` 继续记录名号、本相、现状、蚀相、言语、羁绊、羁绊描述，并新增 `性格`、`互动方式`。
- 魔人 / 魔物主角：`/主角/本源/{名号,特征,状态}`。本源是角色自身，不是另一个 NPC。
- NPC 同样允许 `人设`；只有实际设定存在时才使用其 `星灵` 或 `本源`。

## 人物等级

人物表单只让玩家填 `等级（1～70，选填）`，不要求手填层级。现有星辉内核负责换算：

- Lv1–10：见习 / 孳生体
- Lv11–25：正式 / 蚀魂者
- Lv26–40：精英 / 化渊者
- Lv41–55：战姬 / 噬星者
- Lv56–70：传奇 / 渊厄

## 其他已保留

能力 / 招式仍直接显示名称、档位、系别、本能类别/类型、蓝耗、效果；名称留空时客户端做确定性本地命名。简介自动生成保持短文本，卡片最多三行。普通扩展抽屉直接显示星海工坊及更新状态。
